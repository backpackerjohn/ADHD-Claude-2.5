W-05

Full Warm Start briefing (gap ≥ 14 days) — mobile & web

Flow F3 (crown jewel): Shelf → resting thread → this briefing → four buttons → W-07. Five fixed sections, then exactly four buttons. Content below is Maya's Day-32 return, verbatim from the validation script.

W-05 annotations

1Digest-first guardrail (R6): the briefing is synthesized from the Thread's maintained Digest + last 3 Breadcrumbs — never raw history. Every claim in "where you were / what changed" must trace to Digest or Breadcrumb content; the model omits, never invents.

2Verbatim-quote verification (R6, hard rule): each quoted line must byte-match a stored Spark; a deterministic post-generation verifier checks every quoted_spark_id. Mismatch → strip quote → regenerate once → else insufficient-memory state. Never hallucinated memory.

3Spark quotes render in serif italic with the 2px amber rule + date — the user's own words are sacred material, visibly distinct from AI prose (brand §4.3). Long-press (mobile) / right-click (web) opens the "that's not what I meant" dispute sheet (see States section).

4One ember per screen (law §9.1): "Do it now" is the only primary. Snooze & Shrink are quiet; "Retire with honor" is quiet + dusty blue — an exit with dignity, never alarm-colored. All targets ≥ 44px, ≥ 8px apart.

5Time is soft: "since mid-March", never "47 days ago" — precise elapsed counters are guilt numerals (never-render rule).

6"What changed" windows to since-last-touch only; deadline rendered as lead time ("5 weeks out"), never a countdown.

7Exactly one Pebble, sized 2 min–1 hr to restart momentum, never a wall of steps (law §9.7). Timer is optional — no time pressure by default.

8Loading: shell renders instantly; skeleton shimmer appears only after 300ms; gap copy is honest. Budget p50 < 2.5s, p90 < 4s; 8s hard timeout → AI-down fallback (below). Briefing cached 24h per thread — no double spend on re-open.

9Web is memory-first: sidebar Doorway · Shelf · Search · Loose Sparks · Settings, quick-capture pinned top (C). Briefing column capped at 62ch measure (law §9.6). No badges or dots on nav — ever.

W-05b

Briefing tiers — whisper (< 3 days) & brief (3–13 days)

Tier selection is pure date math, never AI. The whisper is one inline line at the top of the thread story (W-04b), not a screen. The brief is a compact card with the same four buttons.

W-05b annotations

10Deterministic tiering: whisper < 3 days · brief 3–13 days · full ≥ 14 days — computed by date math, not AI. Whisper copy is Haiku-tier, pre-computed by the nightly Batch, rendered from cache instantly.

11The whisper is one line inline at the top of the thread — no screen takeover, no buttons except the Pebble chip. Warmth state always carries a text label ("warm · touched yesterday"), never color alone (brand law §3.4.3).

12Brief tier = where-you-were + last Breadcrumb + one Pebble + the same four-button row. Same grounding rules as W-05; the Breadcrumb is shown verbatim (auto-notes are neutral-dotted, Sparks amber-dotted).

W-06

Unstick — the bounded 3-exchange script (flow F5)

Entered from any Pebble ("why is this hard?"). All three exchanges shown as the complete script — the whole interaction, laid flat. Content is Maya's Day-8 accountant-email freeze.

W-06 annotations

13Bounded, NOT a chat. Exactly three exchanges: name the feeling → shrink the stakes → 2-minute physical first move. The hard cap is structural — no fourth exchange exists in the UI, and there is no free-form chat surface anywhere in the flow. Progress marker reads "1 of 3". Haiku-tier; free tier 3 Unsticks/day.

14Feeling chips + free text. named_feeling is the most sensitive field in the product: encrypted at rest, excluded from analytics (counts only, never content), never used for training without explicit opt-in. Transcript appends to the thread's story and the golden eval set.

15Terminal choice: one primary ("Start the 2 minutes") + quiet "Not today", accepted without guilt — the Thread rests, nothing turns red, no follow-up ping. Session is never resumable; a new freeze starts a fresh session.

16Misuse valve: after 3 sessions on the same Pebble in one day, Ember offers Shrink instead ("this step might just be too big").

W-07

Do-it-now focus surface — the Pebble and nothing else

Reached one tap from W-05 ("Do it now") or straight from the Doorway (F2, canonical ruling D-016). Whisper line at top, the Pebble, the thread's key links, a capture field, a done button. Nothing else renders.

W-07 annotations

17Whisper line at top per canonical ruling D-016 (F2): one tap to action; the thread's whisper context is embedded here so re-entry never detours through the thread view.

18Bounded surface: whisper + Pebble + key links + capture field + done. Nothing else — no thread history, no step list, no nav bar. Timer optional, shown as soft estimate ("~3 min"), never a countdown.

19The one primary is "Done". The Unstick entry ("I'm stuck") is quiet and always present at the point of performance (F5). Inline capture files through the normal M1 pipeline without leaving focus.

20Leaving any time (back, app switch) auto-writes a Breadcrumb — zero user effort, no time-outs on input (law §9.9); tomorrow's Doorway knows where she stopped.

21Deterministic reward, < 300ms: the glow bloom + haptic tick + copy variant fire from a pre-built, novelty-rotating local pool before any network round-trip (delay-discounting compliance). Bloom ≤ 300ms, soft-settle easing; reduced-motion collapses it to a simple fade. Ember minutes accrue deterministically — no AI in the loop, no streaks.

W-08

Retire with honor — confirm → Closing Note preview → saved to gallery (flow F7)

Three steps, left to right. Step 2 is overlay O-05 (detailed in its own section below). Content: Maya retiring Macramé on Day 32.

W-08 annotations

22Retirement never happens on one tap. Explicit confirm with ink-weight typography — a dignified exit, not a destructive warning. No red, no trash-can iconography (brand Do/Don't #5). Copy avoids "deleted / abandoned / gave up".

23AI drafts the Closing Note (Sonnet-tier) → user optionally edits → explicit confirm stores it with the retired thread. Backing out keeps the thread untouched. Full editable state: O-05 below.

24Retired card = neutral surface + sage "finished/growth" mark + note excerpt. Recovery path: "Pick this back up?" un-retires; the thread rekindles warm with a "back from retirement" whisper, and the note is preserved as an immutable log entry — history is never erased, only continued.

O-03

Snooze picker — tomorrow · next week · when I touch it

Bottom sheet over the briefing. Three presets, no date grid, no guilt.

O-03 annotations

25Three soft presets only — no calendar, no exact dates, no "overdue in 7 days". Snoozing creates zero reminder debt and no badge anywhere. Deterministic: snooze handling and expiry are code, not AI.

26Selecting a chip shows the confirmation line in place ("Resting until next week. It'll keep — embers do.") then the sheet dismisses (200ms exit). A snoozed briefing expires when the thread is next opened and regenerates fresh — the gap has changed. Thread shows a quiet "briefing resting" glyph; no countdown, no red.

O-05

Closing Note preview — editable before saving

The overlay inside W-08 step 2, shown here in its editing state.

O-05 annotations

27Note body renders in the serif quote voice — a warmth moment. Fully editable inline (dashed frame + caret shown); the draft persists if she leaves mid-edit and restores on return (no time-outs on input, law §9.9).

28One primary: "Keep this note & retire" — the explicit confirm required by M3 (retirement is never a single tap). "Never mind" abandons the retirement entirely with no side effects. Once saved, the note lives in the Finished & Retired gallery and survives un-retiring as immutable history.

O-10

Crisis-resource sheet — static, warm, human resources

Shown when local patterns (+ Haiku assist) detect crisis language in a capture or an Unstick exchange. The response itself is fully deterministic — never AI-improvised.

O-10 annotations

29Deterministic static response — never AI-improvised. Detection is local patterns with a Haiku assist; the sheet content is fixed copy reviewed by humans. Warm serif voice, no clinical framing, no alarm color (terracotta/ink only — no red, per color law §3.4.2).

30Resources are real, free, 24/7: 988 Lifeline (call/text), Crisis Text Line (HOME to 741741), findahelpline.com internationally. Call/text buttons are ≥ 52px targets. The single ember goes to the highest-value action.

31Privacy: the triggering content is never logged to analytics (counts only, never content — same rule as Unstick's named_feeling) and never leaves the account. Exit is gentle and guilt-free; the thread simply keeps.

STATES

Honest fallbacks & the quote-dispute affordance

F3 failure paths: memory too thin → honest fallback; AI unavailable → raw story with last breadcrumb pinned; briefing lands wrong → "that's not what I meant". A thin briefing that admits thinness beats a rich briefing that lies (R6).

States & dispute annotations

32Never fake richness (R6): a thread with < 3 Sparks, or a failed grounding check, gets the honest state — "here's everything I have" — with raw Sparks verbatim plus one generic small Pebble ("re-read your last three notes"). The same four buttons remain: re-entry always ends in action.

33AI-down fallback is deterministic: W-04 raw thread story (chronological Sparks, steps, Breadcrumbs from M2) with the last Breadcrumb pinned on top and a gentle rest-toned banner. Never a blank screen; never "try again later" as the only content — the user came to re-enter, and re-entry must always be possible. Triggered by outage, offline, or the 8s briefing timeout after one silent retry.

34The pinned breadcrumb answers "where was I?" without any AI. Banner uses the dusty rest palette — informative, never alarming; no error codes.

35Long-press (mobile) / right-click (web) any quoted line. The pressed quote shows the standard 2px ember focus ring. Every quote carries this affordance because every quote passed byte-match verification — disputes are about framing, not fabrication.

36Effects: quote suppressed thread-wide immediately; the Spark itself is never edited — the optional correction is stored alongside it; the dispute feeds the R6 eval set; one regenerate is offered. Repeated disputes lower the thread's briefing confidence, and future briefings prefer raw Sparks over paraphrase.
